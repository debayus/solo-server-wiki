    Crafting

    SYS-04

    Summary

    Three input slots (Core Material, Support Material, Element Stone) produce weapons, armor, tools, or potions. It can be done anywhere.

    Rules

    • Categories: Weapon, Armor, Tool, Potion (CraftCategory).
    • Slot 1 accepts items with type = MATERIAL and role = core or any; slot 2 accepts items with type = MATERIAL and role = support or any; slot 3 accepts only ELEMENT_STONE (optional). Element stones never go into slots 1–2. A recipe with stone: null matches only when slot 3 is empty.
    • Matching: item + minimum quantity per slot, slot order matters, and only recipes from the active tab category (Crafting screen).
    • If one combination satisfies more than one recipe, the recipe with the largest total ingredient quantity is chosen; if equal, the largest Core Material quantity.
    • One item ID may fill only one crafting slot; the picker does not show items that are already in another slot.
    • When the player picks an item for a slot, the slot holds the total quantity of that ID in the bag (all stacks); crafting uses only the quantity the selected recipe requires.
    • Tapping a recipe in the list (Crafting screen) fills each slot with the exact quantity of that recipe, and matching uses the quantity in the slot. A manual choice through the picker (trial and error) still puts in the entire stack, and then the largest matching recipe is chosen.
    • If a slot is filled by tapping a recipe and some slot has too little quantity, CRAFT is disabled with the text "Missing materials"; the combination is not matched to another recipe until the player changes a slot manually.
    • Two recipes in the same category must not have identical slot contents (item and quantity).
    • A combination that matches no recipe cannot be crafted.
    • A combination that matches a recipe that is not yet at the Unlocked stage can be crafted; the recipe then unlocks (Recipe Discovery).
    • The result is always 1 item with upgrade_level 0.
    • No station is needed: crafting can be done anywhere through the menu (Stations). The result always goes into the bag because the bag is unlimited (Stacking).
    • Recipe data: the zone catalogs (CNT-Z1 … CNT-Z7, including potion recipes) and tool recipes in Recipes. Screen: Crafting screen.
