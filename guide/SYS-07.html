    Equipment & Set Bonuses

    SYS-07

    Summary

    Five equipment slots (4 armor + 1 weapon) and armor set bonuses.

    Rules

    • Slots: weapon, head, body, hands, legs.
    • Only ArmorData with a matching slot can go into an armor slot.
    • Equipping an item returns the old item to the Bag. Unequip and Swap (a 1:1 exchange with an item from the Bag) are always allowed because the Bag has no limit (Stacking).
    • Set bonuses are counted from the number of equipped armor pieces with the same set_id: ≥ 2 pieces → bonus_2; 4 pieces → bonus_2 + bonus_4.
    • Screen: Equipment screen.
