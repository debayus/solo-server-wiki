    Kematian & Respawn

    SYS-08

    Ringkasan

    Mati tidak menghilangkan item; pemain hidup kembali di api unggun terakhir.

    Aturan

    • Terjadi saat hp ≤ 0. Urutan lengkapnya: Urutan kematian.
    • respawn_point diperbarui setiap kali pemain mengetuk Api Unggun di dunia, dengan nilai posisi pemain saat tiba dalam jarak aktif (Rumus & angka) dan layar Memasak terbuka, disertai notifikasi sys.respawn_saved ([PRASASTI] Api unggun ini akan membangkitkanmu.) Memasak tidak diperlukan.
    • Pengecualian aturan pembaruan: memilih "Tetap tinggal" di akhir ending otomatis mengeset respawn_point ke titik respawn api unggun Ruang Takhta (Peta, Ending).
    • Respawn di respawn_point. Nilai awal: titik awal Z1 (Peta, Keadaan awal).
    • Setelah respawn: HP penuh, Stamina penuh, Lapar = 50 (walau sebelumnya lebih tinggi), semua buff hilang. Urutan reset: Urutan kematian.
    • Tidak ada item, XP, atau level yang hilang.
    • Penyimpanan otomatis tidak terjadi saat pemain mati; player_respawned hanya membersihkan player_dead dan tidak menyimpan (Autosave).

    Urutan kematian

    1. hp ≤ 0: player_died dipancarkan. Pemain langsung kebal dan input dikunci.
    2. Pudar keluar (death_fade_out): layar memudar ke hitam. Monster yang sedang Kejar atau Serang melepas target dan Kembali (Perilaku monster). Boss di arena ikut Kembali dan pulih; boss_fight_active menjadi false (Autosave).
    3. Tahan (death_hold): layar hitam, teks Prasasti sys.disconnected ("[PRASASTI] Tubuhmu runtuh... api unggun memanggilmu kembali.").
    4. Teleport + reset (tepat di akhir tahan, layar masih hitam): pemain dipindahkan ke respawn_point. Urutan reset nilai:
      1. hapus semua buff;
      2. hitung ulang stat turunan (Stat turunan);
      3. HP = HP maks baru, Stamina = Stamina maks baru, Lapar = 50;
      4. stats_changed dipancarkan sekali.
    5. player_respawned dipancarkan; player_dead dibersihkan (tanpa menyimpan).
    6. Pudar masuk (death_fade_in): layar kembali terlihat. Kebal dan kunci input berakhir tepat saat pudar masuk selesai; tidak ada kebal tambahan setelah respawn.

    Durasi ketiga tahap adalah token death_fade_out, death_hold, dan death_fade_in di Token alfa dan durasi (angka hanya ada di sana).

    Aturan selama urutan (dari player_died sampai pudar masuk selesai):

    • Pemain kebal terhadap semua damage: monster, Lapar (HP turun saat Lapar 0), panas, dan petir (Survival, Bahaya lingkungan). Input pemain diabaikan.
    • Jam game dan timer spawn tetap berjalan (tidak di-pause); durasi urutan memakai waktu nyata.
    • Urutan kematian tidak memakai efek glitch (dihapus); pudar selalu berlangsung, juga bila reduce_effects aktif (Efek).
    • HUD disembunyikan selama urutan dan muncul lagi setelah player_respawned (HUD).

    Respawn ke zona lain: bila respawn_point berada di zona yang berbeda dari tempat pemain mati, respawn diperlakukan seperti masuk zona biasa (Masuk zona): zona itu dimuat, toast masuk zona muncul, zona dicatat di visited_zones, dan autosave entered_zone dicoba (Autosave). Penanda masuk zona dipancarkan setelah player_respawned agar autosave tidak tertahan; mekanismenya di Alur scene.

    Layar: HUD (HUD). Api Unggun yang ditaruh lewat Mode Taruh (Interaksi) berfungsi sama seperti Api Unggun bawaan peta, termasuk memperbarui respawn_point saat diketuk (Aturan).
