    Stats & Level

    SYS-01

    Summary

    Four core stats are raised with level-up points; derived stats are calculated from the core stats and equipment.

    Rules

    Core Stats

    StatNameEffect
    STRStrengthATK
    AGIAgilityCrit, max Stamina
    VITVitalityMax HP, DEF
    INTIntelligenceFood buff duration, element resist

    Respec

    Only with the item Rebirth Crystal: all points in allocated_points are added to unspent_points, then allocated_points is cleared (all 0) and the core stats return to their starting values; then Level Up screen opens in respec mode. If allocated_points is all 0, Rebirth Crystal is rejected without being consumed, with the toast sys.respec_nothing ("No points to reset.").

    Formulas & Numbers

    Derived Stats

    All numbers in this section.

    StatFormula
    Max HP100 + VIT × 10
    Max Stamina100 + AGI × 5
    Max Hunger100 (fixed)
    ATKweapon_atk_final + STR × 2
    DEFΣ armor_def_final + VIT × 1
    Crit (%)5 + AGI × 0.5 + weapon_crit_bonus, max 50
    Element X resist (%)Σ resist_X from armor + INT × 0.5, max 75
    Buff durationbase_duration_sec × (1 + INT × 0.01)

    weapon_atk_final and armor_def_final already include the upgrade multiplier (Upgrade & Evolution). weapon_crit_bonus = the crit_bonus of the equipped weapon (0 if no weapon). Order of calculation:

    1. Equipment values (already including upgrades) + flat set bonuses (Equipment & Set Bonuses) for ATK, DEF, Crit, and Resist. flat bonuses for max HP and max Stamina are added directly after the formula in step 2. percent bonuses apply only to ATK, DEF, max HP, and max Stamina; Crit and Resist accept only flat bonuses.
    2. The formulas in the table above.
    3. percent set bonuses.
    4. Active food buffs.
    5. The maximum caps for Crit (50) and Resist (75) are applied to the final value after step 4.

    Rounding and bonus-summing rules:

    • percent bonuses within one step (step 3 or step 4) are summed first, then multiplied once: value × (100 + Σpercent) / 100. The percent from step 3 and the percent from step 4 remain two separate multiplications.
    • In step 4, the buff's flat bonuses are added first, then the buff's percent bonuses are multiplied: (value + Σflat) × (100 + Σpercent) / 100.
    • ATK, DEF, max HP, and max Stamina are rounded (round.5 away from zero) once, after step 4. There is no rounding between steps.
    • Crit and Resist stay decimal (not rounded); their caps are applied in step 5.

    When max HP rises or falls (buffs, equipment), current HP does not change, except that it is clamped if it exceeds the new max HP. The same rule applies to Stamina.
