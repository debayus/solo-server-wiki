    Stasiun

    SYS-09

    Ringkasan

    Api Unggun dan Landasan Rune adalah objek dunia. Sejak, crafting, upgrade, dan memasak tidak butuh stasiun: Api Unggun tetap menjadi titik respawn, dan kedua stasiun menjadi pintasan untuk membuka layarnya.

    Aturan

    • Stasiun bisa sudah ada di peta, atau ditaruh pemain memakai Kit Api Unggun lewat Mode Taruh. Kit Landasan Rune dihapus; Landasan Rune yang sudah ditaruh di save lama tetap ada dan berfungsi seperti Landasan Rune bawaan peta.
    • Sigil Pengrajin: kelana bisa merakit, meningkatkan, dan memasak di mana saja. Saat Main Baru, setelah dunia siap, toast Prasasti sys.sigil_granted muncul sekali ("[PRASASTI] Sigil Pengrajin menyala di telapak tanganmu. Merakit dan memasak kini bisa di mana saja.").
    • Lokasi taruh valid bila: petak berada di zona tempat pemain berada (current_zone; petak di zona lain tidak valid, sys.place_invalid_zone), petak tanpa tabrakan, tidak ditempati titik bahan atau stasiun lain, bukan petak bahaya (heat_zone, air dalam), tidak di dalam arena boss, tidak di Ruang Takhta (bagian dalam Istana Hampa) sebelum Gerbang Istana terbuka, dan berjarak ≤ 96 px dari pemain (Euclid dari pusat pemain ke pusat petak, inklusif). Item tanah dan monster tidak memblokir petak.
    • Alasan petak tidak valid ditampilkan sebagai toast: sys.place_invalid_blocked (tabrakan, titik bahan, atau stasiun lain), sys.place_invalid_hazard, sys.place_invalid_arena, sys.place_invalid_core_locked, sys.place_invalid_too_far, sys.place_invalid_zone (Interaksi).
    • Bila petak gagal lebih dari satu syarat, toast menampilkan alasan pertama menurut prioritas: zona lain (sys.place_invalid_zone) > terlalu jauh (sys.place_invalid_too_far) > Ruang Takhta tersegel (sys.place_invalid_core_locked) > arena (sys.place_invalid_arena) > bahaya (sys.place_invalid_hazard) > terhalang (sys.place_invalid_blocked).
    • "Petak valid terdekat" (Interaksi) memakai metrik jarak yang sama (pusat pemain ke pusat petak, Euclid); bila seri, dipilih y terkecil, lalu x terkecil.
    • Maksimal 10 stasiun taruhan per zona (batas stasiun), dihitung total Api Unggun dan Landasan Rune taruhan (Landasan Rune taruhan hanya ada dari save lama), tidak termasuk stasiun bawaan peta. Zona yang dihitung adalah current_zone. Batas diperiksa saat "Pakai" alat taruh (Inventory (Tas)) untuk current_zone: bila penuh, muncul toast sys.station_limit "Batas stasiun di zona ini tercapai.", mode taruh tidak dibuka, dan alat tidak terpakai. Bila saat "Pakai" tidak ada petak valid dalam jangkauan, muncul toast sys.place_invalid_blocked, mode taruh tidak dibuka, dan alat tidak terpakai. Zona taruhan dibatasi ke current_zone.
    • Stasiun taruhan punya collision, permanen (tidak bisa dibongkar), dan berfungsi sama seperti stasiun bawaan peta.
    • Mengetuk stasiun di dunia: pemain berjalan ke stasiun lalu layarnya terbuka langsung (pintasan; layar yang sama juga bisa dibuka dari menu di mana saja). Landasan Rune → Crafting (Upgrade lewat tab navigasi), Api Unggun → Memasak.
    • Tidak ada mode baca dan tidak ada syarat jangkauan (menggantikan): tombol aksi CRAFT/MASAK/UPGRADE/EVOLUSI tidak pernah dinonaktifkan karena jarak ke stasiun. Teks status "Butuh Landasan Rune" dan "Butuh api unggun" dihapus. near_campfire / near_anvil tidak lagi dipakai oleh layar.
    • Crafting yang dibuka dari Landasan Rune memilih kategori Senjata, atau kategori terakhir yang dibuka dalam sesi permainan itu.

    Rumus & angka

    StasiunDibutuhkan untukJarak aktif
    Api UnggunSet respawn_point (Kematian & Respawn); pintasan ke Memasak64 px, antar-tepi collision (pemain dan stasiun)
    Landasan RunePintasan ke Crafting64 px, antar-tepi collision (pemain dan stasiun)

    Radius collision untuk jarak antar-tepi = ⅓ lebar ukuran badan objek, sama dengan Makhluk: stasiun 32×32 → ≈ 10,7 px, ukuran badan pemain 48 px → 16 px. Jarak antar-tepi = jarak pusat dikurangi kedua radius; nilai ≤ 64 px berarti dalam jangkauan, tanpa pembulatan.
