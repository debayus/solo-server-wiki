    Stasiun

    SYS-09

    Ringkasan

    Api Unggun dan Landasan Data adalah objek dunia yang membuka fungsi memasak, crafting, dan upgrade.

    Aturan

    • Stasiun bisa sudah ada di peta, atau ditaruh pemain memakai Kit Api Unggun / Kit Landasan Data lewat Mode Taruh.
    • Lokasi taruh valid bila: petak berada di zona tempat pemain berada (current_zone; petak di zona lain tidak valid, sys.place_invalid_zone), petak tanpa tabrakan, tidak ditempati titik bahan atau stasiun lain, bukan petak bahaya (heat_zone, air dalam), tidak di dalam arena boss, tidak di bagian dalam Inti Server sebelum gerbang terbuka, dan berjarak ≤ 96 px dari pemain (Euclid dari pusat pemain ke pusat petak, inklusif). Item tanah dan monster tidak memblokir petak.
    • Alasan petak tidak valid ditampilkan sebagai toast: sys.place_invalid_blocked (tabrakan, titik bahan, atau stasiun lain), sys.place_invalid_hazard, sys.place_invalid_arena, sys.place_invalid_core_locked, sys.place_invalid_too_far, sys.place_invalid_zone (Interaksi).
    • Bila petak gagal lebih dari satu syarat, toast menampilkan alasan pertama menurut prioritas: zona lain (sys.place_invalid_zone) > terlalu jauh (sys.place_invalid_too_far) > Inti terkunci (sys.place_invalid_core_locked) > arena (sys.place_invalid_arena) > bahaya (sys.place_invalid_hazard) > terhalang (sys.place_invalid_blocked).
    • "Petak valid terdekat" (Interaksi) memakai metrik jarak yang sama (pusat pemain ke pusat petak, Euclid); bila seri, dipilih y terkecil, lalu x terkecil.
    • Maksimal 10 stasiun taruhan per zona (batas stasiun), dihitung total Api Unggun dan Landasan Data, tidak termasuk stasiun bawaan peta. Zona yang dihitung adalah current_zone. Batas diperiksa saat "Pakai" alat taruh (Inventory (Tas)) untuk current_zone: bila penuh, muncul toast sys.station_limit "Batas stasiun di zona ini tercapai.", mode taruh tidak dibuka, dan alat tidak terpakai. Bila saat "Pakai" tidak ada petak valid dalam jangkauan, muncul toast sys.place_invalid_blocked, mode taruh tidak dibuka, dan alat tidak terpakai. Zona taruhan dibatasi ke current_zone.
    • Stasiun taruhan punya collision, permanen (tidak bisa dibongkar), dan berfungsi sama seperti stasiun bawaan peta.
    • Mengetuk stasiun di dunia: pemain berjalan ke stasiun lalu layarnya terbuka langsung. Landasan Data → Crafting (Upgrade lewat tab navigasi), Api Unggun → Memasak.
    • Di luar jangkauan, layar terkait tetap bisa dibuka dalam mode baca: daftar resep, isi otomatis, dan pemilih tetap aktif; hanya tombol aksi (CRAFT/MASAK) yang nonaktif. near_campfire / near_anvil dihitung saat layar dibuka.
    • Prioritas teks status tombol aksi: "Butuh Landasan Data" (ui.station.need_anvil) / "Butuh api unggun" (ui.station.need_campfire) lebih dulu, lalu "Bahan kurang" (ui.craft.missing), lalu "Tas penuh" (ui.craft.bag_full). Prioritas di Upgrade / Evolusi: State khusus.
    • Crafting yang dibuka dari Landasan Data memilih kategori Senjata, atau kategori terakhir yang dibuka dalam sesi permainan itu.

    Radius collision untuk jarak antar-tepi = ⅓ lebar ukuran badan objek, sama dengan Makhluk: stasiun 32×32 → ≈ 10,7 px, pemain (48 px) → 16 px. Jarak antar-tepi = jarak pusat dikurangi kedua radius; nilai ≤ 64 px berarti dalam jangkauan, tanpa pembulatan.
